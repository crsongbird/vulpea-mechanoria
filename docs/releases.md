# Release names

Each shipped release takes the next name, from Sol outward: the Sun, then each planet in order of its distance from
it, each planet followed by its moons in order of their distance from the planet (named moons only, as the IAU lists
them). A planet's own release is its name alone (`Mars`); a moon's is the planet's and the moon's with an en dash
(`Mars–Phobos`). The current name is in `src/release.js`.

The order begins:

1. Sol
2. Mercury
3. Venus
4. Earth
5. Earth–Moon
6. Mars
7. Mars–Phobos
8. Mars–Deimos
9. Jupiter, then its moons from Metis outward (Metis, Adrastea, Amalthea, Thebe, Io, Europa, Ganymede, Callisto, …)

After Jupiter come Saturn, Uranus and Neptune with theirs; past Neptune, Ruby names what comes next.
