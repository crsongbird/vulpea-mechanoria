# Vulpéa Mechanória

*Land of the mechanical foxes.*

An open-world walking and survival game on a ringworld: the land curving up into the sky, rim walls taller than
mountains, machines in the wilds, foxes and kitsune at the shrines. It plays in a web browser on phones, keyboards and
controllers.

Made with [Babylon.js](https://www.babylonjs.com/).

```sh
npm install
npm run dev
```

It is early: the first release, **Sol**, lays the seed's land round you to walk across. The design is in
[docs/design.md](docs/design.md).
